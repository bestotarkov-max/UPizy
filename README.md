# UPizy

Upscale video 720p/1080p → 2K/4K on the GPU, with optional RIFE frame interpolation (60/120 fps).
Native Windows tool written in Rust — a single `.exe`, no Python, no Visual Studio.

- 🇷🇺 [Русская документация](README.ru.md)
- 🇬🇧 [English documentation](README.en.md)

| Engine | Strength |
|---|---|
| AI · Real-ESRGAN | Maximum detail on clips and anime |
| Anime · Anime4K | Anime episodes in 15–20 minutes |
| GPU · libplacebo | Fast, clean upscale of whole films |
| Turbo · CUDA | Minutes instead of hours |

The interface is available in Russian and English (`RU` / `EN` in the window header).
